## 路线概览

<Image src={cover} alt="前端学习路线" />

一条主线：**基础 → 框架 → 工程化 → 实战**。

## 第一阶段：基础

- **HTML/CSS**：语义化、布局（Flex/Grid）、响应式
- **JavaScript**：语法、DOM、异步、ES6+

```js
const skill = await learn('JavaScript');
console.log(skill); // 基础扎实
```

## 第二阶段：框架

选一个主流框架深入：**React / Vue**。

## 第三阶段：工程化

构建工具、代码规范、测试、CI/CD。

## 第四阶段：实战

用真实项目检验学习成果，输出作品集。

> 学习没有捷径，但有更短的路——多写、多总结、多分享。

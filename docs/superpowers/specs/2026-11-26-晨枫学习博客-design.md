# 晨枫的学习之路 — 博客网站设计文档

- **日期**：2026-11-26
- **状态**：已获用户批准
- **作者**：晨枫（技术经理 / 兼职产品经理）

## 1. 概述

为记录个人学习历程与经验总结，搭建一个个人技术博客网站。

### 目标
- 记录学习历程、发布经验总结文章
- 支持大量图片展示
- 视觉风格潮流好看（暗色霓虹风）
- 部署在 GitHub Pages，零成本零维护

### 范围
第一版包含：文章发布与展示、分类/标签/归档、站内搜索、深色模式、RSS、灯箱、阅读进度条。
**不包含**：评论功能、在线写作后台、用户系统。

## 2. 需求汇总

| 维度 | 决策 |
|---|---|
| 技术形态 | 静态博客 |
| 框架 | Astro（最新稳定版）+ TypeScript |
| 内容格式 | MDX（`.mdx`，支持在文章中嵌入组件） |
| 内容结构 | 分类 + 标签 + 归档 |
| 功能 | 站内搜索、深色模式、RSS、灯箱、阅读进度条 |
| 视觉风格 | 暗色霓虹风（深色 + 霓虹渐变 + 毛玻璃拟态） |
| 部署 | GitHub Pages（GitHub Actions 自动部署） |
| 站点名 | 晨枫的学习之路 |
| 图片量 | 大（需重点考虑优化与加载性能） |

## 3. 技术方案

采用「Astro + 本地 Markdown 内容」方案（用户已确认方案 A）：

- **Astro**：静态站点生成，MDX 内容集合（Content Collections）
- **Pagefind**：构建时生成静态搜索索引，无需后端
- **手写霓虹主题**：全局 CSS 变量 + 组件样式，零 UI 框架依赖
- **Shiki**：Astro 内置代码高亮，自定义霓虹配色
- **@astrojs/rss**：生成 RSS 订阅

## 4. 内容模型

每篇文章 frontmatter：

```yaml
---
title: 从零开始学前端的一百天
description: 一句话摘要
category: 前端          # 单分类
tags: [React, 学习笔记]  # 多标签
pubDate: 2026-11-26
updatedDate: 2026-11-30  # 可选，更新时间
heroImage: ./cover.png   # 封面图（可选）
draft: false             # 草稿，true 时不发布
---
```

- 分类：`category` 单值字段
- 标签：`tags` 数组
- 归档：按 `pubDate` 年月分组
- 草稿：`draft: true` 的文章不参与构建

## 5. 站点结构与路由

| 路由 | 页面 |
|---|---|
| `/` | 首页：霓虹 Hero + 最新文章卡片流 + 分类入口 |
| `/posts/[slug]` | 文章详情：正文 + 目录 TOC + 上一篇/下一篇 + 标签 |
| `/category/[分类]` | 分类列表页 |
| `/tags/[标签]` | 标签列表页 |
| `/archive` | 归档页（按年月分组） |
| `/about` | 关于我 |
| `404` | 自定义霓虹风 404 页 |

## 6. 视觉设计（霓虹主题）

### 色彩系统
- **底色**：深空蓝黑（`#0b0f1a` 系），营造沉浸暗色氛围
- **三色霓虹渐变**：青 `#22d3ee` → 紫 `#a855f7` → 粉 `#f472b6`
  - 用于：标题渐变文字、按钮、徽章、发光边框、进度条

### 设计语言
- **玻璃拟态**：卡片半透明背景 + `backdrop-filter: blur` 毛玻璃 + 霓虹光晕阴影（hover 发光）
- **字体**：标题用几何粗黑（Space Grotesk，中文回退系统粗黑）；正文用高可读性字体
- **细节**：霓虹下划线、渐变色进度条、卡片 hover 光晕、平滑过渡动画

### 深色模式
- 默认 = 霓虹深色；提供浅色模式切换（同样霓虹渐变，浅色底 + 白色毛玻璃卡片）
- 支持「跟随系统 + 手动切换」，选择用 `localStorage` 记忆
- 实现方式：CSS 变量 + `data-theme` 属性切换

## 7. 功能实现细节

| 功能 | 实现方式 |
|---|---|
| 站内搜索 | Pagefind 生成索引；霓虹风搜索弹层（顶部按钮 → 弹层实时结果，ESC 关闭） |
| 深色模式 | CSS 变量 + `data-theme`；导航栏切换按钮；`localStorage` + 跟随系统 |
| 阅读进度条 | 文章页顶部霓虹渐变进度条，随滚动填充 |
| 灯箱 | 自定义轻量组件：点击放大、多图切换、ESC 关闭、触摸滑动 |
| RSS | `@astrojs/rss` 生成 `/rss.xml` |
| 代码高亮 | Shiki + 霓虹配色 |
| 返回顶部 | 文章页右下角返回顶部按钮 |

## 8. 图片策略（大量图片）

- **存放规范**：`src/assets/images/<分类>/`，按分类归档
- **优化**：Astro 内置 `<Image>` 组件 — 自动压缩 WebP/AVIF、生成响应式多尺寸、懒加载
- **封面**：`heroImage` 字段引用
- **灯箱**：文章内图片点击放大查看原图
- **体积管理**：GitHub Pages 免费站点上限 1GB。给用户的使用建议：
  - 截图类 → PNG；照片类 → JPG/WebP
  - 批量压缩工具建议
  - 定期检查总大小

## 9. 部署（GitHub Pages）

- 项目初始化 git，创建 GitHub 仓库
- `.github/workflows/deploy.yml`：push 到 main → 安装依赖 → 构建 → 部署 Pages
- `astro.config` 配置 `base` 为仓库名
- 构建产物 `dist/`，GitHub 端开启 Pages 源为 Actions

## 10. 错误处理

- 自定义霓虹风 404 页面
- 图片缺失兜底：`alt` 文本 + 样式占位，不出现破图

## 11. 测试与验收

硬性验收标准：
1. `npm run build` 构建通过（含类型检查）
2. `npm run dev` 本地预览逐页检查（首页 / 文章 / 分类 / 标签 / 归档 / 关于 / 404）
3. 响应式检查：桌面 / 平板 / 手机
4. 内容校验脚本：frontmatter 字段完整、图片引用路径真实存在
